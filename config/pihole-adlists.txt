# Pi-hole adlists, applied by `provision.sh adlists`.
#
# ⚠ gravity.db is authoritative for adlists. /etc/pihole/adlists.list is a v5
# artefact and is IGNORED by v6 — editing it does nothing. This file is the
# repository's declarative source, imported into gravity.db and then compiled by
# `pihole -g`.
#
# Format:  <url><TAB or spaces><comment>
# Blank lines and lines starting with # are ignored.
#
# Importing is additive and idempotent: an address already present keeps its
# current enabled/disabled state and comment, so a list you disabled by hand
# stays disabled across re-runs. Nothing here is ever deleted — see the
# "disabled, not deleted" note in docs/OPERATIONS.md §7.6.
#
# ⚠ These overlap heavily by design; that is not waste. Overlap is what makes
# any single list's outage or bad update non-fatal. Before adding more, read
# §7.6: the marginal unique-domain count of a tenth list is usually near zero,
# and every list is a source of false positives you will have to debug.
